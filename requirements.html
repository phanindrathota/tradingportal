Trade Portal Requirements

Functional and data requirements for the trading journal workflow.

Back to Portal

Core Functional Requirements

  • Manual trade entry form with required fields and validation.
  • Editable and removable trade logs.
  • Auto-calculation of Profit/Loss percentage from Entry/Exit prices.
  • Profit/Loss color coding (green for wins, red for losses).
  • Performance summaries for Day, Week, Year, and Running Total.
  • Filtering by Year, Week, and specific Day.

Data Fields

  • Date
  • Expiration Date
  • Ticker
  • Entry Price
  • Exit Price
  • Profit/Loss Percentage
  • Running Total Profit Value
  • Reason for Trade

Import / Export / Persistence Requirements

  • Import from Excel/CSV.
  • JSON export of trade logs.
  • Save logs to local folder using browser file APIs when available.
  • Persist logs in browser localStorage.
  • Optional Python local server API: GET/POST /api/trades.
